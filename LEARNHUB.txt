**RUNNING THE PROJECT**
1. Start Your Backend Server
Open terminal in your lms-backend directory.

Run the backend server:
node app.js

Make sure you see:
MongoDB connected
Server running on port 5000

2.open frontend public path in cmd 
C:\Projects\LearnHub\frontend\public>npx serve .






**POSTMAN TESTING:**
register:-POST http://localhost:5000/api/auth/register
{
  "name": "Vital",
  "email": "vital@example.com",
  "password": "pass123",
  "role": "admin"
}

login:-POST http://localhost:5000/api/auth/login
{
  "email": "vital@example.com",
  "password": "pass123"
}

course:-GET http://localhost:5000/api/courses  (copy login given token and paste in headers bearer token)
            if you want to add courses login same with admin token and post course in body json
